Por qué no nos basta

Cada palabra recorre la lista de las vistas

Lento

Incómodo

Parte 1

El diccionario

Una colección de parejas clave: valor. A cada valor se llega por su clave, no por su posición.

Claves y valores

Entre llaves, con dos puntos en cada pareja

conteo = {"de": 20, "que": 9, "hidalgo": 2}

print(conteo["de"])
print(len(conteo))
20
3

Los corchetes son los de la lista, pero dentro no va una posición sino una clave. len cuenta las parejas.

  • Un for sobre el diccionario recorre las claves.
  • El orden es el orden en que se agregaron.
  • for palabra, veces in conteo.items() es el mismo desempaquetado de for i, x in enumerate(lista).

Parte 2

El patrón de conteo

Si la palabra ya tiene entrada, se le suma uno. Si no, se crea con uno.

Paso a paso

Cada palabra toca una sola casilla

def frecuencias(palabras):
    """Cada palabra a las veces que aparece."""
    conteo = {}

    for palabra in palabras:
        if palabra in conteo:
            conteo[palabra] += 1
        else:
            conteo[palabra] = 1

    return conteo

Verde: la clave es nueva. Naranja: ya estaba y suma uno. El segundo "de" no agrega nada.

La forma que vas a ver en todas partes

get funde el if y el else en una línea

conteo = {"de": 2, "los": 1}

print(conteo.get("de", 0))
print(conteo.get("rocín", 0))
2
0

get(clave, defecto) devuelve el valor, o el defecto si la clave no está. Nunca da KeyError.

def frecuencias(palabras):
    """Cada palabra a las veces que aparece."""
    conteo = {}

    for palabra in palabras:
        conteo[palabra] = conteo.get(palabra, 0) + 1

    return conteo

Hace lo mismo que la versión con if. Aquella dice mejor lo que pasa; esta es la que vas a encontrar escrita en todas partes.

Del conteo a la respuesta

La más común es el acumulador de siempre

def mas_comun(conteo):
    """La pareja (palabra, veces) con más apariciones."""
    mejor, maximo = "", 0

    for palabra, veces in conteo.items():
        if veces > maximo:
            mejor, maximo = palabra, veces

    return mejor, maximo

Las diez primeras

Buscar el mayor, apartarlo y volver a buscar

def mas_comunes(conteo, k):
    """Las k parejas más frecuentes, de mayor a menor."""
    quedan = dict(conteo)
    resultado = []

    for vuelta in range(k):
        palabra, veces = mas_comun(quedan)
        resultado.append((palabra, veces))
        del quedan[palabra]

    return resultado

Parte 4

Por qué buscar una clave no cuesta nada

VACIAS funcionaría con corchetes. ¿Por qué un conjunto?

En vivo · archivo busqueda.py

Buscar el -1, que no está

import time


def segundos_por_busqueda(coleccion, x, veces):
    """El tiempo medio que tarda `x in coleccion`."""
    inicio = time.perf_counter()
    for vuelta in range(veces):
        encontrado = x in coleccion
    return (time.perf_counter() - inicio) / veces


for n in [1_000, 10_000, 100_000, 1_000_000]:
    lista = list(range(n))
    conjunto = set(lista)
    en_lista = segundos_por_busqueda(lista, -1, 50)
    en_conjunto = segundos_por_busqueda(conjunto, -1, 100_000)
    print(f"{n:>9} elementos: lista {en_lista * 1e3:7.3f} ms,"
          f" conjunto {en_conjunto * 1e9:4.0f} ns")
     1000 elementos: lista   0.015 ms, conjunto   40 ns
    10000 elementos: lista   0.252 ms, conjunto   95 ns
   100000 elementos: lista   2.402 ms, conjunto   79 ns
  1000000 elementos: lista  31.582 ms, conjunto  123 ns
  1. 1_000_000 es un millón: el guion bajo solo ayuda a leer.
  2. Antes de correr: si la lista crece 10 veces, ¿cuánto crece el tiempo?
  3. Corre. La lista se multiplica por diez en cada fila. El conjunto no se mueve.
  4. Si sobra tiempo, cambia -1 por 0. La lista lo encuentra enseguida: depende de dónde esté.
Lo que acabamos de medir

Diez veces más elementos, diez veces más tiempo. O nada.

Escala logarítmica: cada raya vale diez veces la de abajo. Las barras salen de la tabla anterior; en tu máquina cambian los números, no la forma.

La intuición, sin la implementación

El valor dice en qué casillero está

  • Una lista guarda en fila. Para decir no está tiene que mirar todos.
  • Un conjunto o un diccionario calcula a partir del propio valor un número que dice en qué casillero guardarlo. Al buscar hace la misma cuenta y va directo.
  • Como los casilleros con el nombre de cada estudiante: tu nombre te dice cuál es el tuyo.
  • Ese número se llama hash. Si una clave cambiara, cambiaría su casillero y se perdería. Por eso una lista es unhashable.

Cómo se calcula y qué pasa cuando dos valores caen en el mismo casillero es materia del segundo semestre.

Lo que queda para la clase que viene

¿Y si quiero todas ordenadas?

mas_comunes busca el mayor, lo aparta y vuelve a buscar. Para diez palabras está bien. Para las 719 recorre el diccionario 719 veces.

La conferencia 7 escribe esto y otros dos métodos de ordenar, les cuenta las operaciones y los pone a correr sobre listas que crecen.

Una pista

Hoy medimos una búsqueda que crece como n y otra que no crece. Ordenar así crece como n × n: pregunta al aula qué pasaría con la novela entera, que tiene más de veintitrés mil palabras distintas.

Resumen

Lo que te llevas de hoy

  • d[clave] lee, d[clave] = valor agrega o reemplaza, del d[clave] quita. Una clave que no está da KeyError.
  • in pregunta por las claves, nunca por los valores.
  • El patrón de conteo: conteo[x] = conteo.get(x, 0) + 1.
  • for clave, valor in d.items() recorre las parejas en el orden en que se agregaron.
  • Las claves son inmutables: números, cadenas, tuplas. Un diccionario sí se modifica; dict(d) lo copia.
  • Un conjunto no tiene repetidos ni orden. set() es el vacío, porque {} es el diccionario vacío. |, &, -.
  • Buscar en un conjunto o diccionario cuesta lo mismo con diez elementos que con un millón. En una lista, en proporción a su tamaño.
