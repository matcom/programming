Índices y rebanadas

La misma fila de casillas, con un carácter en cada una

Una diferencia con las listas

En una cadena, in busca un pedazo

Lista
3 in [1, 2, 3] pregunta si 3 es uno de los elementos.
Cadena
"ola" in "hola" pregunta si "ola" aparece seguido dentro de "hola". Sirve para buscar una palabra en un texto, y las listas no tienen nada parecido.
if letra in "aeiouáéíóú":
    vocales += 1
La diferencia grande

Las cadenas no se pueden modificar

palabra = "hola"
palabra[0] = "H"
TypeError: 'str' object does not support item assignment

Toda operación sobre una cadena construye una cadena nueva y deja la original intacta. Para "cambiarla" se reasigna el nombre.

mayuscula = palabra.upper()   # palabra sigue siendo "hola"
palabra = palabra.upper()     # ahora el nombre apunta a "HOLA"
Por qué importa

Sin la sorpresa de los nombres compartidos

Lista · la clase pasada
a = [1, 2, 3]
b = a
b.append(4)
print(a)
[1, 2, 3, 4]

Dos nombres, una sola lista. Cambiar por un nombre se ve por el otro.

Cadena · hoy
a = "hola"
b = a
b = b.upper()
print(a)
hola

Nadie puede cambiar "hola". b.upper() fabrica otra cadena y b pasa a nombrarla.

Las cadenas se comportan como los números: inmutables. Un int tampoco se modifica, se reemplaza.

Métodos de cadena

Funciones que trae la cadena y que se llaman con un punto detrás del valor. Ninguna la modifica.

Los que vas a usar todo el tiempo

La pareja importante

split te devuelve a la clase pasada

Para pensar · ejercicio 7b de las notas

¿Cuántos pedazos en cada caso?

print(len("a,b,,c".split(",")))
print(len("a b  c".split()))
4
3
La regla
split(",") parte en cada coma, y entre dos comas seguidas queda una cadena vacía: ["a", "b", "", "c"].

split() sin argumento trata cualquier tramo de espacios como un solo separador y nunca devuelve cadenas vacías: ["a", "b", "c"].

Esa diferencia importa al leer un CSV, donde un campo vacío entre dos comas es un dato.

Parte 3

Archivos

El texto de verdad no se escribe a mano: vive en archivos.

De disco a variable

open da un archivo; read da una cadena

"r" · leer
El modo por defecto. Si el archivo no existe, FileNotFoundError.
"w" · escribir
Crea el archivo, y si ya existía lo borra antes de escribir.
"a" · agregar
Escribe al final de lo que ya había. No borra nada.
La forma correcta de abrir

with cierra el archivo aunque algo falle

with open("quijote.txt", encoding="utf-8") as archivo:
    contenido = archivo.read()

print(len(contenido))
print(contenido[:60])
1101
En un lugar de la Mancha, de cuyo nombre no quiero acordarme

Se lee así: abre el archivo, llámalo archivo mientras dure el bloque, y ciérralo al salir. contenido sigue vivo después, porque es una variable normal.

La codificación

Un archivo son bytes; la codificación dice qué letra es cada uno

Cuando la tabla no es la correcta

Los dos síntomas de la codificación equivocada

Bytes UTF-8 leídos como cp1252
open("quijote.txt", encoding="cp1252")
años     →  aÃ±os
salpicón →  salpicÃ³n

No hay error. Cada byte de la ñ se lee como una letra aparte: C3 es Ã, B1 es ±. El programa sigue con basura dentro.

Bytes cp1252 leídos como UTF-8
b"Espa\xf1a".decode("utf-8")
UnicodeDecodeError: 'utf-8' codec can't decode
byte 0xf1 in position 4: invalid continuation byte

Aquí sí se cae. F1 no es una secuencia válida en UTF-8.

Escribe encoding="utf-8" siempre, aunque tu sistema lo tenga por defecto. El programa tiene que funcionar también en la computadora del profesor, y los sistemas viejos de esta universidad exportan en cp1252.

Leer línea por línea

Un archivo se recorre con for, una línea por vuelta

Parte 5

El proyecto: contar las palabras

Cuántas palabras tiene el archivo, cuál es la más larga y el promedio de letras.

El primer problema

split a secas deja la puntuación pegada

SIGNOS = ".,;:¿?¡!()«»\"'—-"


def limpiar(texto):
    """Devuelve el texto en minúsculas y sin signos de puntuación."""
    texto = texto.lower()
    for signo in SIGNOS:
        texto = texto.replace(signo, " ")
    return texto
Cómo se reparte el trabajo

Cuatro funciones, cada una se explica en una frase

El código

Con las piezas de hoy, sale corto

def palabras_de(ruta):
    """Devuelve la lista de palabras de un archivo de texto."""
    with open(ruta, encoding="utf-8") as archivo:
        return limpiar(archivo.read()).split()


def mas_larga(palabras):
    """Devuelve la palabra más larga de la lista."""
    mayor = palabras[0]
    for palabra in palabras:
        if len(palabra) > len(mayor):
            mayor = palabra
    return mayor


def promedio_de_letras(palabras):
    """Devuelve el promedio de letras por palabra."""
    letras = 0
    for palabra in palabras:
        letras += len(palabra)
    return letras / len(palabras)
palabras = palabras_de("quijote.txt")

print(f"{len(palabras)} palabras")
print(f"la más larga es '{mas_larga(palabras)}'")
print(f"promedio de {promedio_de_letras(palabras):.2f} letras")
196 palabras
la más larga es 'entresemana'
promedio de 4.46 letras

mas_larga es el acumulador de la clase pasada con len(palabra) en lugar del valor. Guardar el mejor visto hasta ahora es un patrón que vas a escribir cien veces.

Lo que hoy no podemos responder

¿Cuántas veces aparece cada palabra?

Con dos listas en paralelo se puede, pero cada palabra nueva obliga a recorrer la lista entera para ver si ya estaba.

palabras_vistas = ["en", "un", "lugar", "de", "la"]
conteos         = [  5,    3,      1,   20,   4]

La estructura que resuelve eso es el diccionario, y es la clase que viene: la frecuencia de cada palabra de este mismo texto, y las diez más comunes.

Resumen

Lo que te llevas de hoy

  • Una cadena es una secuencia: len, índices desde cero y negativos, rebanadas y for, igual que una lista.
  • En una cadena, in busca un pedazo, no solo un carácter.
  • Las cadenas son inmutables. Todo método devuelve una cadena nueva y deja la original intacta.
  • split convierte texto en lista de palabras; join hace lo contrario.
  • Los archivos se abren con with open(ruta, encoding="utf-8"), que los cierra solo.
  • El modo "w" borra lo que había. Recorrer un archivo con for da una línea por vuelta, con su \n.
  • try y except dejan que el programa atienda un error en vez de morirse. Nombra siempre el error concreto.
